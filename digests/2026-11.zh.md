## 🎙 PODCASTS

一句话要点：Arca 把 agent 放进金融服务的心脏，但把钱和客户的最后一步牢牢交给人。

Latent Space 在 AI Engineer New York 现场对话 Arca 的 Aman Singh。Arca 近期为一家 AI 原生财富管理公司募得 6400 万美元，服务覆盖财务规划、税务、保险与遗产规划，客户从刚卖掉公司的创业者到准备提前退休的科技高管，也有买第一套房的小家庭。Singh 强调 AI 在 Arca 不是替代顾问，而是替代顾问周围的所有工作，客户不直接接触 AI，感受到的是人类顾问的同理心加上此前行业做不到的服务密度。

技术层面，Arca 用 Anthropic 与 OpenAI 的前沿模型，Claude 长期是主力，此前也用过 Gemini 和 OpenAI。选型不看外部榜单，而看内部针对自家 harness 各项能力的 benchmark。Singh 举了一个反例：尽管外部评测对 Luna 评价很高，实际用起来比预期慢很多、成本也高。他们的原则是模型无关，harness 自建，不把智能的所有权交出去。他明确表示对 Anthropic 的模型很看好，但对直接依赖 managed agents 这类产品持保留态度，因为记忆与运营知识的归属决定了谁能影响业务。

一个组合调整案例横跨十天。客户因税单来信，agent 负责分析资金当前分布、算出变现十万美元的最优路径，但任何资金移动、资产变现或直接联系客户都必须有人在场，系统与托管方有深度 API 集成，guardrail 是确定性的。长周期的关键在于记忆系统：每个客户当前在做什么、谁负责哪一步、接下来几天和长期各要跟踪什么，都由 agent 共同维护，另有一个类似"做梦"的反思过程持续更新状态。新信号进来时，一个全新的 agent 能迅速搞清楚"我们正在处理一笔大税单"。

安全上，每次写库都有 LLM 验证，边缘检测 prompt injection，数据外发时既查 PII 也用小模型共识防外泄。合规关心可审计性，而 Arca 默认记录每一次变更，人和 agent 一视同仁。最带劲的一句是 Singh 对 AI 原生与"有 AI 工具的公司"的区分：**"在 Arca，agent 催人的次数比人催 agent 更多。"** 服务是 7×24 主动运行的。反馈闭环上，员工的每次修改都带原因并成为 eval，每晚有 meta agent 基于真实 trace 提议 harness 改动，但上线前仍由工程师把关，因为 Singh 观察到 agent 改 prompt 往往会把一个小修复膨胀成整段重写。
