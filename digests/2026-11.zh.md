## 🎙 PODCASTS

一句话要点：Arca 把 agent 放在业务流程的中心，人退到资金动作与客户关系的关口上。

Latent Space 在 AI Engineer New York 2026 现场对话 Arca AI 平台负责人 Aman Singh。Arca 是一家 AI 原生财富管理公司，近期融资 6400 万美元，服务覆盖财务规划、税务、保险与遗产规划，客户从刚卖出企业的创始人到准备提前退休的科技高管，也有买第一套房的小家庭。Singh 强调 AI 在 Arca 不是替代顾问，而是替代顾问周围的所有工作，客户不直接面对 AI，感受到的是人类顾问的同理心加上此前行业做不到的服务密度。

技术侧，Arca 自建模型无关的 harness，按任务复杂度分层调用模型，税务分析这类任务走最重的一层，可以是 Opus 档、Sonnet 档或重型 GPT 模型，后台活动则用更轻的模型。选型由内部 benchmark 决定而非外部榜单，Singh 举例说某个外部评测亮眼的模型实际太慢、成本也高。安全上，所有限制都是确定性的，把决策权从 agent 手里拿走；每一次写库都有一次 LLM 校验，输入端检测 prompt injection，数据外发时既做 PII 确定性检查，也用一组小模型做共识以防数据外泄。审计默认开启，agent 与人类在 UI 上的每一次改动都会留下变更日志。

最 memorable 的一句是：“与其说是人给 agent 写提示，不如说是 agent 在给人派活。” 他以一个十天跨度的税单为例：分析部分全自动，但任何资金移动、资产清算或直接联系客户都必须有人类在环，agent 会把对的人在对的时点拉进来，并附上可审阅可调整的方案。长任务的连续性靠按客户维护的记忆系统加每日的反思过程来维持，新信号进来时新 agent 能迅速接上上下文。反馈闭环上，员工的每次修改或取消都要写明原因，这些反馈与 agent trace 配对入库，每晚由 meta agent 提出 harness 改动建议，但上线前仍保留人类工程师把关，因为 Singh 观察到 agent 改 prompt 容易把一个小修变成整段重写，难以泛化。他还提到 Anthropic 进入金融服务是行业背书，但 Arca 不愿依赖 managed agents，因为“拥有自己的智能”才握得住业务。
