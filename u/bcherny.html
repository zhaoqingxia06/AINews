    Boris Cherny launched Claude Ship in beta for Team and Enterprise plans, a year after Opus 4.5 became the first model to write 100% of his code. Anyone can use /ship, and admins can enable it per GitHub repo; he suggests starting with one repo and running Approvals in observe mode until trust is earned. The stack splits into Code Review for bugs, PR Steward for fixes and failing checks, and Claude Approvals to approve what team policy allows, with the last two in beta. His claim: it multiplies velocity because he no longer waits on code review or babysits PRs.
